# Pour Bubu 💗
Animation interactive (HTML/CSS/JS) avec musique.

## Mettre en ligne sur GitHub Pages
1. Crée un dépôt sur github.com (ex: `pour-bubu`), public.
2. Clique « Add file » > « Upload files » et glisse `index.html`, `chanson.mp3` (et ce README).
3. « Commit changes ».
4. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)` > Save.
5. Après ~1 min, le lien apparaît : https://TON-PSEUDO.github.io/pour-bubu/

Garde `index.html` et `chanson.mp3` dans le même dossier.
